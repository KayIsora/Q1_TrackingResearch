# Handling the supplied Consensus PDF

## Role of the PDF

The user supplied a four-page Consensus output titled *Research gap in the problem of human tracking using robots/UAVs*. It was useful as a **search lead**: it highlighted long-horizon target recovery, identity preservation in crowds, cross-platform evaluation, low-cost sensing, and search-and-rescue as topics to check.

## It is not evidence in this repository

**PROJECT POLICY.** The PDF is not committed or redistributed. Its own notice says it is for personal, non-commercial use and that redistribution requires copyright holders’ consent. More importantly, it is an AI-generated synthesis, not a primary scientific source.

Every retained factual statement in this repository is instead linked to a primary paper, official dataset record, benchmark toolkit, or official agency source in [references.md](../references/references.md). If a claim from the PDF cannot be traced to such a source, it remains an open question rather than a repository conclusion.
