# Claim taxonomy

This repository uses the labels below in every decision and discussion. A label is part of the claim, not cosmetic wording.

| Label | Meaning | What an AI or reader may do with it |
|---|---|---|
| **FACT — cited** | Directly supported by the attached reference. | Quote or summarize it with the cited source and its limits. |
| **INTERPRETATION — reasoned** | Reasoning from one or more facts. | Challenge the inference; do not recast it as a published conclusion. |
| **PROJECT DECISION — provisional** | Scope selected for this project. | Preserve it unless a documented decision gate changes it. |
| **HYPOTHESIS — untested** | A claim intended for experimental falsification. | Do not write it as an achieved contribution. |
| **PROVISIONAL TARGET** | Internal go/no-go condition. | Do not attribute it to a paper or standard. |
| **OPEN QUESTION** | Unknown information that could change the project. | Seek evidence; do not fill it with an assumption. |

## Minimum claim test

Before committing a sentence that sounds factual, ask:

1. Is it external and verifiable? If yes, cite a source.
2. Does the source support this exact wording, not merely a related topic?
3. Is the claim conditional on device, data split, evaluation protocol, or licence? State the condition.
4. Is it actually a local choice or hypothesis? Use the appropriate label instead.
