## 6. SpikeTrack surviving distinction/collision

### Cumulative collision boundary

- **Conditional SNN compute is known:** SEENN/DT-SNN vary timesteps; SEMM routes spiking experts; STATA and TP-Spikformer reduce token/block work.
- **Conditional tracker compute is known:** Depth-Adaptive Policies, DyHiT, ABTrack, and ARTrack-AC vary depth, blocks, routes, or capacity with frame/segment difficulty.
- **Search-conditioned historical retrieval is known:** RFGM selects reference tokens for the current search region.
- **Distractor-aware state and mode control are known:** DaSiamRPN, KeepTrack, DAM4SAM, and MVLM model distractors/competitor margins and use them for memory or search decisions.

Therefore, a proposal to “gate MRMs by confidence,” “skip easy-frame retrieval,” or “add distractor awareness” is cumulatively collided. The material distinction is narrower:

> **Within the unchanged SpikeTrack SDTV3/asymmetric/six-MRM/center-head core, objectively measured target–distractor ambiguity predicts an out-of-sample interaction with the marginal contribution of identifiable MRM scale and template/time retrieval paths (including the T1–T3 contrast), and that interaction governs real physical retrieval execution rather than masking outputs after the cost has already been paid.**

No reviewed source implements or tests that condition-by-retrieval-contribution relationship. TP-Spikformer is the closest compute-side partial collision; RFGM is the closest retrieval-side partial collision; DAM4SAM and MVLM are the closest ambiguity-side partial collisions. Their cumulative scope forbids broad novelty language but does not erase the stated interaction.

### Prohibited broad claims

The following must not be claimed: first adaptive SNN inference; first dynamic-timestep or early-exit SNN; first dynamic-computation tracker; first spiking-token pruning; first search-conditioned memory selection; first distractor-aware tracker; first confidence-gated memory/retrieval; or first easy/hard tracking route. SpikeTrack already owns its released asymmetric MRM design and T3 gate; this audit does not re-claim those baseline components.

### Minimum diagnostic evidence still required

This is a requirement statement only; no diagnostic experiment was started.

1. Predefine an outcome-independent ambiguity measure and distractor/non-distractor strata; avoid using final tracking failure to define the condition.
2. Measure per-MRM scale and template/time marginal effects under identical checkpoints, with the S256-T1 anchor and S256-T3 controlled comparison, and test the ambiguity × retrieval-path interaction with uncertainty intervals.
3. Show the retrieval signal predicts held-out marginal utility and target–competitor separation, not merely confidence or average frame difficulty.
4. Demonstrate **physical** path non-execution and measured latency/operations/energy on the same deployment path; an attention mask or zeroed output alone is insufficient.
5. Establish that reduced retrieval preserves unambiguous-frame accuracy while retaining or improving ambiguous-frame discrimination; report failure cases and condition-specific, not only aggregate, results.
6. Retain the stated SpikeTrack core and compare against fixed-budget, random, confidence-only, TP-Spikformer-style token importance, and generic easy/hard routing controls.

## 10. FARTrack surviving distinction/collision

### Direct and cumulative collision

The locked question is cumulatively occupied:

1. **Measuring validity and rejecting unsafe evidence:** BackTrack, STDTrack, DTPTrack, DynaTrack, UncTrack, QDMN, and runtime cycle-validation foundations.
2. **Physically removing historical/static/dynamic template information:** ATPTrack, LMTrack, UTPTrack, ETCTrack, STDTrack, QDMN, and RMem.
3. **Joint robustness plus compute motivation:** ATPTrack, LMTrack, UTPTrack, and ETCTrack explicitly remove noisy/redundant reference information while reducing subsequent work.
4. **Occlusion/disappearance/distractor memory protection:** DTPTrack, DynaTrack, UncTrack, DAM4SAM, BackTrack, and NeighborTrack.
5. **Adaptive capacity inside autoregressive tracking:** ARTrack-AC.

The only residual wording found is:

> Per-frame validity dynamically changes the number of whole FARTrack raw templates before patch embedding and dense attention, so invalid frames consume no embedding or Q/K/V work, with a condition-specific causal effect after occlusion/disappearance.

That is a placement/granularity specialization: apply known reliability gating and physical pruning one stage earlier, at whole-frame granularity, inside FARTrack. It can be useful engineering and may save more work, but it is an ordinary combination of published mechanisms, not a materially new relation. Retaining FARTrack’s multi-template, trajectory/command-token, IFAS temporal-template, and autoregressive core does not create novelty by itself because those are baseline-specific integration constraints.

### Prohibited broad claims

Do not claim: first reliability/confidence/uncertainty/quality/validity-aware template update; first backward/cycle-validated template update; first physical dynamic/static/historical-template-token pruning; first historical-template compression for robustness and efficiency; first bounded or quality-selected tracking memory; first distractor/occlusion-aware memory management; first adaptive compute in autoregressive tracking; or first observation that extra historical templates/tokens can be redundant or harmful. “Use fewer templates,” template caching, generic token pruning, confidence gating, memory eviction, ABSENT/ReID, and recovery modules do not restore novelty.

### Gate consequence

No diagnostic experiment was begun. Physical pre-embedding removal, latency/MAC/memory-traffic evidence, validity calibration, condition interactions, and comparisons against ATPTrack/LMTrack/UTPTrack/ETCTrack and reliability-memory controls could establish **efficacy**, but positive diagnostics would support a FARTrack-specific implementation study rather than rescue the present novelty claim. A later reconsideration would need a qualitatively new relationship beyond combining validity gating with earlier physical pruning.
