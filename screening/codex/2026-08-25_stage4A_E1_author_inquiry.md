3. Which OTB source and version were used, or alternatively, could you provide checksums for the evaluated image files and ground-truth annotations?
4. Which operating system and version were used for that run?
5. Which GPU model or models were used for that run?
6. Which Python version was used for that run?
7. Which PyTorch version was used for that run?
8. Which CUDA and cuDNN versions were used for that run?
9. Which random seeds and deterministic settings, including cuDNN and cuBLAS settings if applicable, were used for that run?
10. Were the released OTB raw predictions produced with S256-T1, S256-T3, or another configuration, and what was the exact configuration file name?

Thank you for any details you can share.
