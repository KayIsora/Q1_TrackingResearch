## 3. Final eight presentation branches

The final manually drawn graph should use these eight solution branches:

1. **STATIC STRUCTURAL COMPRESSION**
   - always-executed stage/depth/width/backbone becomes physically smaller.

2. **KNOWLEDGE PRESERVATION**
   - training-only transfer preserves task-facing or intermediate behavior after reduction.

3. **SPARSIFICATION / PRUNING**
   - tokens/features/blocks/channels/representations are selected or removed.

4. **TEMPLATE–SEARCH ASYMMETRY & REUSE**
   - initialization-only/stable target evidence is separated from per-frame work.

5. **SPATIAL EFFICIENCY**
   - search sampling or input resolution is reduced while protecting target evidence.

6. **TEMPORAL MEMORY & ROBUSTNESS**
   - persistent evidence quality, update policy, or contextual state is improved.

7. **SNN-SPECIFIC REPRESENTATION & TRAINING**
   - spike dynamics, timestep, state, cache semantics, or SNN-specific regularization define the mechanism.

8. **DYNAMIC COMPUTATION — CROWDED / DEFERRED**
   - execution path varies by input; this branch is a caution/deferred band, not the primary scientific lane.

Branches 1 and 2 must be visually coupled but not merged:

- Branch 1 answers **WHAT TO REDUCE?**
- Branch 2 answers **WHAT TO PRESERVE / HOW TO TRAIN?**
